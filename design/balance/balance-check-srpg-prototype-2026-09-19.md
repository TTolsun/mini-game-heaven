# Balance Check: 간파·모방·체득 수련전

## Data Sources Analyzed

- `native/app/srpg/BattleData.h`
- `native/app/srpg/BattleModel.cpp`
- `native/tests/BattleModelTests.cpp`
- `docs/game-direction.md`, `docs/srpg-design.md`

## Health Summary: CONCERNS

기능과 완주 가능성을 검증한 첫 시제품입니다. 전략의 다양성이나 반복 플레이의 재미가 검증된 상태는 아닙니다. 높은 체득 보상과 적의 단순한 방향 예고가 학습을 쉽게 해 주지만, 체득 후 난도가 급격히 낮아집니다.

## Outliers Detected

| 항목 | 구현 수치와 계산 | 해석 |
|---|---|---|
| 일반 타격 | 피해 6, 기 비용 없음입니다. | 체력 30·44·62의 적에게 각각 5·8·11회의 성공 공격이 필요합니다. |
| 미완성 모방 | 피해 10 / 기 20 = 기당 0.5 피해입니다. | 체득을 위한 위험한 과정입니다. 적 공격선에서 사용하면 추가 피해 6을 받습니다. |
| 체득 붕권 | 피해 18 / 기 15 = 기당 1.2 피해입니다. | 모방보다 기당 피해가 2.4배이고 밀쳐내기로 공격도 끊어 성능 상승 폭이 큽니다. |
| 벽 충돌 | 추가 피해 6으로 총 24입니다. | 지형이 유효한 선택이지만 벽에 고정하는 반복 전략을 확인해야 합니다. |
| 기 축적 | 제자리 연속 20·30·50, 상한 100입니다. | 위험한 칸에서 맞으면 추가 피해 6·기 손실 10·연속 초기화가 적용됩니다. |
| 방어 | 적 피해 10·12·14를 각각 5·6·7로 줄입니다. | 충격 단서 획득에 사용되며 공격 자원을 무료로 회복하지 않습니다. |
| 배움 | 종류가 다른 단서 3개, 성공 모방 2회입니다. | 같은 안전 행동만 반복해서 단서를 채울 수 없습니다. |

## Degenerate Strategies Found

모델 테스트의 단순 정책은 공격선 밖에서 기를 모은 뒤 체득한 붕권을 사용하여 2번 수련을 6턴, 3번 수련을 7턴에 체력 72를 유지한 채 완료했습니다. 이는 재현된 쉬운 완주 전략이며 전체 밸런스 통과 근거가 아닙니다.

상대는 한 방향 공격선만 준비하므로 옆으로 돌며 모으는 전략을 쉽게 허용합니다. 다음 재미 검증에서는 방향을 바꾸는 적·충전 방해·서로 다른 기술의 관찰 조건 중 최소한의 확장을 비교해야 합니다. 세 수련의 난도를 수치만 높여 해결하지 않습니다.

무한 관찰 단서, 체득 이후 성공 횟수 증가, 실패 후 재도전으로 배움을 누적하는 루프는 막았습니다. 기 축적도 상한이 있고 모든 수련에 종료 턴이 있습니다. 현재 경험치·금화·전리품 경제는 없습니다.

## Progression Analysis

첫 수련의 회귀 경로는 방어 → 같은 방어를 반복해 중복 단서가 없는지 확인 → 공격선 밖으로 이동하며 관찰 → 안전하게 기 모으기 → 첫 모방 → 위치를 바꾸어 다시 모으기 → 두 번째 모방과 체득 → 체득 기술로 승리입니다. 두 번째 모방이 노출 상태이면 피해를 받으므로 새 기술을 얻는 순간에도 전장 위험이 남습니다.

대표 기술의 성능 변화는 확인했습니다. 다만 단서 조건을 모두 알고 시작하면 두 번의 행동만으로 간파할 수 있으므로, 플레이어 스스로 전조를 읽고 발견하는 경험은 추가 플레이테스트가 필요합니다.

## Recommendations

| 우선순위 | 다음 검증 | 의도 |
|---|---|---|
| P1 | 사용자가 안내를 읽기 전 전조와 새 단서를 이해하는지 관찰합니다. | 조건 암기와 스스로 깨닫는 경험을 구분합니다. |
| P1 | 일반 타격 위주의 빠른 승리와 배움을 노리는 승리를 비교합니다. | 배우는 위험을 감수할 동기를 확인합니다. |
| P2 | 체득 후에도 다른 위치·행동이 필요한 적 하나를 시험합니다. | 체득 기술 반복만으로 끝나는 문제를 줄입니다. |
| P2 | 모방 성공 조건을 다양한 상황으로 확장할지 검토합니다. | 단순 횟수와 숙련의 차이를 확인합니다. |

## Values That Need Attention

체득 피해 18·기 15·공격 중단의 결합, 적의 한 방향 2칸 공격, 세 단서의 짧은 발견 시간은 다음 플레이테스트의 조정 대상입니다. 현재 수치는 재미를 확인하는 임시 규칙이며 전체 캠페인 성장 수치로 고정하지 않습니다.
