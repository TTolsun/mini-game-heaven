# 변경 시 지켜야 할 제약

## 모델과 표현

BattleModel은 Android·GLES·Scene을 참조하지 않습니다. 단계와 입력 전체를 검증한 뒤 명령을 적용합니다. preview는 복사본에서 동일 execute를 사용합니다. 마지막 아군의 명령은 적 차례까지 포함하므로 미리보기에도 같은 결과가 포함되어야 합니다. 이벤트·애니메이션이 판정을 바꾸면 안 됩니다.

## 입력과 모달

선택·확정·BACK·화면 전환 때 이전 hit 목록과 포인터를 폐기합니다. 연출 중 입력은 잠그고 종료 후 다시 만듭니다. 턴 종료와 새 여정은 확인창을 사용합니다. 모달 아래의 지도·메뉴는 입력 대상이 아닙니다.

## 자원과 연계

추격은 동료마다 라운드당 한 번이며 추격이 추가 추격·밀기·공격 성공 기를 생성하지 않습니다. 보상은 완료 비트로 한 번만 지급합니다. 재도전과 패배 후 정비는 출전 당시의 배움·발견·약초를 복원합니다. 같은 종류의 단서는 중복 성장하지 않습니다. 행동 경험 상한은 6입니다.

## 저장

wuten-v2.txt에 확정된 캠페인 상태와 출전 체크포인트를 기록합니다. 비전투 단계는 Unit 배열이 비어 있어야 하며, 전투 단계는 편성·유형·좌표·점유·체력·기·승패·보상 이력을 검사합니다. 파싱 실패나 범위 오류 때 기존 모델을 유지합니다. Android/POSIX 임시 파일 교체를 사용합니다. 이전 버전 파일은 독립적으로 남기며 자동 변환하지 않습니다.

## 수명과 검증

효과음은 오디오 참조보다 오래 살아야 합니다. 엔진 의존 방향과 스레드 구조를 유지합니다. 화면은 안전 영역과 비율을 반영하고 한국어 글리프는 소스에서 갱신합니다. 코드 변경 후 빌드·lint·모델/Scene·정책·문서 검사를 수행합니다. 실제 재미와 장시간 다기기 성능은 자동 테스트와 구분합니다.
