# SRPG 설계 결정

## D-001 C++ 핵심 엔진을 유지한다

GameActivity·OpenGL ES·AAudio·한국어 글꼴·햅틱을 재사용하고 규칙은 순수 C++ 모델에 둡니다.

## D-002 조조전식 캠페인 루프를 먼저 완성한다

스토리·도장·출전·진영 턴 전투·결과를 다섯 맵에 연결합니다. 세 동료·네 적 유형·열 기술을 시제품 범위로 고정합니다. 이전 세 수련전의 즉시 체득은 발견·사용 경험·거점 연구로 변경합니다.

## D-003 위치와 순서가 연계를 만든다

밀려난 적 옆의 동료가 제한된 추격을 수행합니다. 재귀 추격과 추격의 공격 성공 기를 금지해 무한 연계를 막습니다. 벽·적 충돌과 직선 기공파는 지원하며 지형 파괴·절벽은 보류합니다.

## D-004 결정적 명령과 진영 턴을 사용한다

아군은 각자 한 번 행동하고, 마지막 행동 또는 확인한 턴 종료 뒤 적 차례를 처리합니다. 명중 난수는 없으며 모델 복사로 예측합니다. 표시 이벤트와 파일 저장은 게임 스레드에서 순차 처리합니다.

## D-005 기를 행동과 위험에 연결한다

기본 타격·사거리 이탈·피격으로 기를 얻고 연속 모음은 노출 위험을 감수합니다. 기술·추격은 일반 타격의 기 보너스를 받지 않습니다.

## D-006 보상과 재도전을 구분한다

각 전투 보상은 한 번만 받습니다. 패배는 배움·약초를 출전 체크포인트로 복원하며 도장 정비도 허용합니다. 기존 앱 업데이트 식별자와 서명은 유지하고 새 저장 버전은 분리합니다.

## D-007 구현과 장기 서사를 구분한다

첫 장은 짧은 대화·배치·전투로 이어지는 시제품입니다. 무태두의 희생부터 손오공과의 만남까지의 전체 캠페인, 상세 관계 이벤트와 최종 캐릭터 아트는 후속 범위입니다. 란란과 기술 규칙은 게임 창작이며 원작 사실과 구분합니다.
