# 마물과 용사의 자동 전투

CastleModel::update는 방어 상태에서만 양수의 유한한 dt를 받습니다. 한 호출의 dt를 최대 0.25초로 제한하고 1/60초 이하 단계로 나누어 진행합니다. `app/castle/CastleModel.cpp:125`

용사는 2.2초 간격으로 등장합니다. 살아 있는 마물은 같은 방의 용사를 공격하며 골렘은 1.2초, 나머지는 0.8초 공격 간격을 사용합니다. 달그림자는 공격력 40%, 드래곤은 65%를 같은 방의 다른 용사에게도 적용합니다. 왕관 슬라임은 살아 있는 동안 초당 체력 3을 회복하며 부활하지 않습니다.

용사는 방에 진입할 때 함정 피해를 한 번 받고, 살아 있는 거주 마물이 있으면 교전하며 없으면 전진합니다. 끝에 도달한 용사는 성 체력을 25 감소시킵니다. 성 체력이 소진되거나 모든 용사가 처리되면 finishRaid로 정산합니다. 마물·용사는 고정 배열로 관리합니다. `app/castle/CastleModel.cpp:179`

파일명 dodge_update는 기존 문서 링크와 설정 호환을 위해 유지한 것이며 현재 내용은 CastleModel 전투입니다. 수치 밸런스의 재미는 별도 플레이테스트 대상입니다.
