# 게임 방향

## 고정한 뼈대

C++ 핵심 엔진을 유지하는 조조전식 SRPG입니다. 이야기·거점·출전·진영 턴 전투·결과를 반복합니다. 전투의 중심은 위치 조정 → 밀쳐내기 → 동료 추격 → 기 활용입니다. 간파·모방·체득은 전투와 도장을 연결하는 기술 성장 체계입니다.

사용자 확정 서사는 무천도사의 어린 시절부터 손오공과의 만남까지입니다. 현재 첫 장은 로시·학선인·창작 동료 란란의 다섯 전투로 구성한 루프 시제품입니다. 짧은 대화와 준비 선택을 사용하며, 원작 전체를 구현한 것은 아닙니다.

## 플레이어가 결정할 것

- 이야기에서는 함께 준비할 사람을 골라 관계·보급·초기 기를 바꿉니다.
- 도장에서는 한정된 보급을 수련·기술 연구·약초에 나눕니다. 장비는 자유롭게 교체합니다.
- 출전에서는 인원과 시작 배치를 결정합니다.
- 전투에서는 순서·이동·밀어낼 방향·추격 위치·기 사용과 축적을 고릅니다.
- 결과에서는 한 번의 보상을 수령하고 발견·성장·관계를 다음 이야기로 가져갑니다.

## 현재 범위와 후속 범위

0.6.0은 캐릭터 3명, 적 4종, 맵 5개, 기술 10개와 위 루프를 구현합니다. 협공은 변위 후 인접한 동료의 제한된 추격이며, 관계 2 이상이면 강화됩니다. 쌍룡격에는 학선인의 위치 조건도 있습니다.

절벽·고저차·장애물 파괴, 상점, 개별 동료 쌍마다 다른 관계, 긴 대화 페이지와 지도별 독립 아트, 장기 성장 트리와 전체 성장기 이야기는 후속 범위입니다. 먼저 다른 배치와 행동 순서가 다른 연계를 만드는지, 배워서 연구할 이유가 있는지 검증합니다. 자동 완주 가능성과 실제 재미는 구분합니다.

구체적인 수치·연구 조건은 [설계](srpg-design.md), 원작 사실과 창작의 경계는 [설정 근거](srpg-lore.md), 테스트 결과는 [검증 기록](validation.md)에 기록합니다.

## 그래픽 방향

조조전의 가독성과 과장된 무술 연출을 목표로 합니다. 가로 1280×720, 48px 타일, 48×64 유닛, 큰 초상화를 공통 규격으로 사용합니다. 초상화는 imagegen, 픽셀 유닛과 애니메이션은 C++ 부품·팔레트로 제작합니다. 우선순위는 초상화 → 타격·기공 효과 → 주요 인물 → 지도입니다. 첫 시제품의 실제 범위는 [그래픽 기준](art/style-guide.md)에 기록합니다.
