# 무천 SRPG 검증 기록 — 2026-09-19

## 빌드와 자동 테스트

0.4.0 개발 코드에서 `gradlew.bat assembleDebug assembleRelease testDebugUnitTest lintDebug --no-daemon`을 실행해 ARM64·x86_64 Debug/Release 빌드와 lint가 통과했습니다. JVM 테스트는 NO-SOURCE이며 네이티브 테스트를 대신하지 않습니다.

`tools/test-srpg.ps1 -Device emulator-5554 -Abi x86_64`와 연결된 Galaxy S25+의 `-Abi arm64-v8a` 실행에서 다음 검사가 통과했습니다.

- 이동 불가·점유·잘못된 행동·잠긴 기술·기력 부족 명령의 거부와 상태 보존입니다.
- 동작·회피·방어 단서, 같은 단서의 중복 방지, 모방과 체득, 위험한 기 축적의 결과입니다.
- 미리보기와 실제 실행 결과의 일치, 벽과 시야, 밀쳐내기와 벽 충돌의 공격 중단입니다.
- 세 수련의 완주, 배움의 다음 수련 계승과 재도전의 입장 상태 복원입니다.
- 저장 교체·재읽기·불완전/범위 오류/중복 점유/후행 데이터 거부와 마지막 허용 턴의 승패 우선순위입니다.
- 실제 BattleScene 입력 대상으로 연속 확정 탭·연출 중 입력 잠금·BACK 이동 취소·안내창·잠긴 기술·학습 저장을 검증했습니다.

순수 모델 테스트는 Linux g++로도 실행하도록 CI 필수 check에 추가했습니다. 에뮬레이터에서 10,000회 미리보기는 약 0.79ms였고 결과 체크섬은 30,000이었습니다. 이는 렌더링을 제외한 작은 모델의 측정이며 FPS나 실기기 성능 보장이 아닙니다.

## 실제 화면과 조작

API 36 x86_64 테스트 에뮬레이터에서 1080×2400과 720×1280 화면을 확인했습니다. 한국어 글꼴·격자·예고 공격선·다섯 행동 버튼·결과 예측이 겹치지 않았습니다. 최종 글꼴은 추가 문자 209개이며 아틀라스 사용 영역은 1024×598입니다.

실제 터치로 방어 → 공격선 회피와 관찰 → 간파 → 기 모으기 → 모방 → 체득 → 붕권으로 첫 수련 승리를 수행했습니다. 0.4.0 APK 업데이트와 강제 종료·재실행 전후의 저장 내용을 대조해 상태가 유지되는 것을 확인했습니다. 관련 logcat에서 네이티브 크래시나 폰트·아틀라스 오류는 관찰되지 않았습니다.

Galaxy S25+ (SM-S936N), Android 16, 1440×3120 실기기에서도 서명된 Release APK로 기존 0.3.0을 삭제 없이 0.4.0 (versionCode 5)으로 업데이트했습니다. 실제 터치로 방어 단서 → 공격선 회피와 관찰 → 기 축적 → 모방 2회 → 체득 → 8턴 첫 수련 승리를 확인했습니다. 강제 종료·재실행 후 체력 51, 기 5, 단서 3/3, 모방 2/2와 승리 상태가 복원됐습니다. 다음 수련 진입 시 배운 붕권이 이어지고 체력·기가 초기화되는 것도 확인했습니다. 해당 앱의 실행 로그에서 크래시나 글꼴·아틀라스 오류는 관찰되지 않았습니다. 음질과 햅틱의 주관적 감각은 검증하지 않았습니다.

검증 캡처는 로컬 build의 `srpg-first.png`, `srpg-mastered.png`, `srpg-short.png`, `srpg-phone-start.png`, `srpg-phone-copy.png`, `srpg-phone-victory.png`, `srpg-phone-restored.png`, `srpg-phone-next.png`에 있습니다. 임시 검증 산출물은 배포 자산이 아닙니다.

## 남은 검증

임시 도형 캐릭터, 세로 화면과 1 대 1 전투를 사용합니다. 전체 1장·동료 협공·장기 성장 계통·고저차·지형 파괴는 구현하지 않았습니다. 실제 사용자 재미 평가와 여러 실기기의 장시간 성능·배터리·오디오 라우트 검증은 남아 있습니다.

단순 정책으로 체득 후 두 수련을 무피해 완주할 수 있었습니다. [밸런스 보고서](../design/balance/balance-check-srpg-prototype-2026-09-19.md)에 이를 한계로 기록했습니다.
