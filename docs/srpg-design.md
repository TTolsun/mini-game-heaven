# DRAGON BALL: 武天 — SRPG 설계 초안

2026-09-19 작성. 장르·C++ 기반·무천도사 성장기·손오공과의 만남이라는 종점은 사용자 확정 사항입니다. 아래에서 현재 구현으로 명시한 세 수련전을 제외한 전체 캠페인·1장 임무·후반 장 구성은 설계 초안입니다. 원작 사실은 [설정 근거](srpg-lore.md)와 구분합니다.

## 재미를 만드는 네 시스템

**간파 → 모방 → 체득**, **거리·방향·넉백**, **위험을 동반한 기 축적**, **전투 행동 기반 성장**을 핵심으로 고정합니다. 서로 분리된 수집 기능이 아니라, 상대의 전조를 읽고 위험을 감수해 배우며 바로 시험하는 한 흐름으로 연결합니다.

목표 경험은 전투 → 관찰·회피·반격·기 축적 → 무술의 단서 발견 → 미완성 모방 → 체득 → 강적에게 활용 → 다음 전투입니다. 행동별 장기 성장에서는 회피·방어·기 운용·협공에 따라 다른 가능성을 열되, 피해를 일부러 반복해서 받는 행위가 최적의 성장법이 되지 않게 해야 합니다.

스승의 말은 해답보다 관찰할 대상을 알려 주는 실마리로 사용합니다. 적의 발·방향·중심 이동을 볼 수 있어야 하며, 플레이어가 알아볼 수 없는 숨겨진 조건을 정답으로 요구하지 않습니다. 첫 시제품은 검증을 위해 조건과 예상 결과를 안내창에 공개합니다.

## 현재 구현: 세 개의 수련전

0.4.0 개발 버전은 7×7 격자에서 로시와 상대 한 명이 싸우는 세 개의 수련전입니다. 전체 캠페인의 진영 턴과 동료 편성 대신, 이동과 행동을 확정하면 상대의 예고된 공격까지 한 번에 처리합니다. 이것은 다섯 맵의 서사 1장을 완성하기 전의 학습 구조 검증용 콘텐츠입니다.

| 단계 | 실제 조건 | 전투에 주는 변화 |
|---|---|---|
| 동작 간파 | 상대 3칸 안에서 시야가 확보된 채 관찰 행동으로 공격을 봅니다. | 동작 단서를 한 번 획득합니다. |
| 발놀림 간파 | 턴 시작 시 예고된 공격선 안에 있다가 안전한 칸으로 벗어나, 3칸 안에서 기술을 봅니다. | 회피 단서를 한 번 획득합니다. |
| 충격 간파 | 공격선 안에서 방어하여 실제 공격을 버팁니다. | 방어 단서를 한 번 획득합니다. |
| 모방 | 세 단서가 모이면 인접한 상대에게 철산격 모방을 사용할 수 있습니다. | 기 20, 피해 10이며 그 차례에 공격받으면 노출 피해 6이 추가됩니다. |
| 체득 | 살아 있는 상대에게 모방을 두 번 성공시킵니다. | 로시류 붕권으로 바뀌어 기 15, 피해 18, 1칸 밀쳐내기가 적용됩니다. |

죽거나 밀쳐져 기술이 중단된 상대에게서는 해당 차례의 단서를 얻지 못합니다. 체득한 기술의 밀쳐내기와 벽 충돌은 상대의 예고 공격을 끊습니다. 벽 충돌은 추가 피해 6을 주며 절벽 추락·고저차·지형 파괴는 아직 없습니다.

기 모으기는 제자리 연속 행동에서 20 → 30 → 50이며 최대 100입니다. 이동하면 연속 효과를 다시 시작하고, 모으는 도중 맞으면 추가 피해 6·기 손실 10과 함께 축적 연속 효과가 끊깁니다. 모방의 불완전함은 첫 버전에서 무작위 빗나감 대신 비용과 노출로 표현합니다.

단서와 성공 횟수는 다음 수련으로 이어집니다. 재도전은 수련 입장 당시의 배움으로 되돌려 실패·재실행을 이용한 중복 성장을 막습니다. 모델 예측·실행, 저장·복원, 실제 화면 입력을 테스트합니다. 상세 결과는 [검증 기록](validation.md)과 [밸런스 검토](../design/balance/balance-check-srpg-prototype-2026-09-19.md)에 기록합니다.

행동별 능력 트리·협공·각성·기술 변형 선택, 고저차와 긴 기공파, 전체 시나리오는 후속 범위입니다. 시제품의 체득 이름 변경은 지정된 변형 한 가지이며 자유로운 기술 제작 기능은 아닙니다.

## 서사 구조

| 구간 | 내용과 성장 | 플레이의 변화 |
|---|---|---|
| 1. 어린 무도가 | 12세 로시의 입문과 어린 학선인과의 만남을 창작합니다. | 이동·타격·방어·협력의 기초를 배웁니다. 서사 1장의 목표 범위는 이 구간의 5개 맵입니다. |
| 2. 무태두 도장 | 함께 수련하며 스승의 가르침을 서로 다르게 받아들입니다. | 공통 기술과 동료별 역할을 익힙니다. |
| 3. 라이벌 | 우정과 경쟁, 강함을 사용하는 방식의 차이를 다룹니다. | 협동 수련·대련·관계 선택이 열립니다. |
| 4. 카린탑 | 힘만으로 풀리지 않는 수련을 경험합니다. | 추적·경로 차단·도달 목표를 가진 소수정예 맵입니다. |
| 5. 천하의 무도가들 | 여러 지역과 무술을 만나며 자기 방식을 찾습니다. | 동료 조합과 지형·임무 유형을 확장합니다. |
| 6. 마족의 등장 | 수련과 대련이 민간인을 지키는 실전으로 바뀝니다. | 구출·방어·증원 대응을 도입합니다. |
| 7. 패배 | 도장의 전력이 무너지고 생존자를 이끌어야 합니다. | 격퇴에서 호위·생존·탈출로 목표가 바뀝니다. |
| 8. 마봉파 | 무태두의 봉인을 위한 기회를 만듭니다. | 호위·시간 확보·봉인 준비 보호가 청년기의 절정입니다. |
| 9. 남겨진 가르침 | 상실 이후의 수련과 학선인과의 갈림길을 다룹니다. | 자기 유파와 기술을 완성하는 독립 시나리오를 제안합니다. |
| 10. 스승이 되는 시간 | 긴 세월을 대표 사건으로 건너뛰며 가르침의 계승을 다룹니다. | 후대 제자를 지도하는 전투·수련을 제안합니다. 인물과 사건은 근거 검토 후 확정합니다. |
| 종장. 바다에서 온 소년 | 거북을 도운 손오공과 만나는 본편 초반 장면으로 이어집니다. | 전투 확장보다 만남과 전승의 의미에 집중하는 짧은 결말입니다. |

1~8장은 사용자의 청년기 구성을 반영합니다. 9장 이후는 사용자가 명시한 종점까지 연결하기 위한 제안입니다. 긴 세월을 매년 플레이하거나 적의 능력치를 계속 올리는 방식으로 채우지 않습니다. 청년기의 주된 동료들이 수백 년 뒤에도 근거 없이 그대로 등장하지 않도록 시대별 편성을 나눕니다.

손오공과의 만남은 본편 초반의 만남으로 정의합니다. 애니메이션 시간여행 장면을 캠페인 중간에 넣어 결말의 의미를 바꾸지 않습니다. 손오공의 입문 이후 본편 모험은 현재 범위에 포함하지 않습니다.

## 전체 캠페인의 전투와 입력 제안

정사각형 격자 위에서 아군·적군 진영이 교대로 행동합니다. 아군 턴 안에서는 인물의 행동 순서를 고릅니다. 한 인물은 이동 후 타격·기술·방어·기 모으기 중 하나를 수행합니다. 제자리 행동도 가능합니다. 방어와 기 모으기는 차례를 소비합니다.

이동은 상하좌우를 사용하고 지형 비용·점유·통행 제한을 반영합니다. 다른 인물이 점유한 칸에 정지하거나 통과할 수 없습니다. 행동 확정 전에는 이동을 취소할 수 있으며, 첫 버전에는 임시 이동으로 발동하는 함정이나 숨겨진 사건을 두지 않습니다.

기본 타격 후 살아 있는 상대가 반격 가능한 사거리라면 한 번 반격합니다. 반격 연쇄는 없습니다. 개별 기술은 기력 비용·범위·반격 가능 여부를 데이터로 정의합니다. 기술별 반격 규칙은 대상 선택 화면에 표시합니다.

명령 확정 전에 이동 가능 범위, 알려진 적의 위협 범위, 예상 피해와 반격 피해, 기력 소모를 보여 줍니다. 첫 버전은 명중·치명타 난수를 제외해 예측 결과를 읽기 쉽게 합니다. 범위 공격은 영향받는 모든 칸과 인물을 표시합니다.

입력 흐름은 인물 선택 → 이동 미리보기 → 행동·대상 선택 → 결과 예측 → 확정 → 연출입니다. 미행동 동료가 남은 턴 종료는 확인을 거칩니다. 연출 중 중복 명령은 막고, 뒤로가기는 대상 선택 취소와 이동 취소 순서로 처리합니다.

## 성장과 두 주인공

로시와 학선인은 공통 기초 수련으로 시작합니다. 로시는 방어·아군 보호·기력 운용, 학선인은 기동·정밀 타격·위치 활용 쪽으로 차별화하는 안을 제안합니다. 한쪽이 공격·이동·생존에서 모두 우월하지 않게 설계합니다. 이는 게임 역할 제안이며 원작의 기술 습득 순서라는 주장이 아닙니다.

기술 성장은 **기본 동작 → 기 운용의 기초 → 개인 기술 연구 → 대표 기술의 완성**으로 구성합니다. 사용자가 예시로 제시한 레벨별 기술 목록은 확정 수치로 사용하지 않습니다. 특히 기 감지·기탄·기공파가 필수로 이 순서에 따라 해금된다는 설정은 보류합니다. 기술마다 원작 근거와 창작 여부, 해금 사건을 기록합니다.

에네르기파는 처음부터 주지 않습니다. 연구·수련·결정적인 성공을 거쳐 익히는 사건으로 설계하되, 완성 시기를 31세 이전으로 임의 고정하지 않습니다. 피콜로 봉인 이후의 긴 수련기도 사용할 수 있습니다. 마봉파는 무태두가 수행하고 플레이어는 필요한 시간을 확보합니다.

관계 선택은 협동 효과·대사·선택 임무에 영향을 주는 안을 제안합니다. 중요한 기술이나 필수 동료를 설명 없는 선택 하나로 영구 차단하지 않습니다. 학선인의 훗날 행보를 바꾸는 대체 역사 분기는 현재 범위에 포함하지 않습니다.

## 1장: 다섯 개의 전투 맵

12세 입문과 아래 사건은 창작입니다. 1장에는 기탄·에네르기파·마봉파를 주지 않고 기본 체술과 협력으로 재미를 검증합니다. 1장의 구조·호위 임무는 피콜로 전쟁보다 작은 사건으로 제안합니다.

| 맵 | 상황 | 목표 | 배울 판단 |
|---|---|---|---|
| 1. 도장으로 가는 길 | 길에서 위험에 처한 사람을 돕습니다. | 로시가 쓰러지지 않고 위협을 제거합니다. | 이동, 타격, 반격 사거리입니다. |
| 2. 입문 시험 | 무태두가 로시의 기본기를 시험합니다. | 예고된 제한 시간 안에 지정 지점에 도달합니다. | 지형 우회, 방어, 공격하지 않고 목표를 달성하는 판단입니다. |
| 3. 같은 문하 | 학선인과 비살상 대련을 합니다. | 대련 상대를 전투 불능으로 만듭니다. 패배 시 같은 맵을 재도전합니다. | 상대 범위를 읽고 먼저 들어갈 시점을 고릅니다. |
| 4. 둘이서 해결할 일 | 두 소년이 함께 사람을 보호합니다. | 보호 대상을 목적지까지 호위합니다. | 행동 순서, 길목 확보, 서로의 역할을 배웁니다. |
| 5. 첫 실전 | 함께 수행하던 일이 예상보다 위험해집니다. | 구조 대상과 두 소년을 탈출시킵니다. | 격파와 임무 달성 사이의 선택, 협력과 철수를 익힙니다. |

맵 사이에 짧은 대화·수련 선택·결과와 다음 맵으로의 진행을 연결합니다. 현재 세 수련전에서 배움의 구조를 검증한 후, 서사 1장의 목표 범위를 다섯 맵의 진행·저장·재개까지 확장합니다.

## 7장의 패배를 플레이로 만드는 규칙

전쟁의 패배는 서사적 고정점이며, 임무는 구조와 탈출로 성공할 수 있습니다. 목표는 **피콜로군 격퇴 → 무태두 보호 → 생존 → 로시와 학선인 탈출**로 전환합니다. 전환 조건은 시나리오 데이터에 명시하고 목표 변경 시 화면과 대사로 알린 뒤 플레이를 재개합니다.

승산 없는 증원을 끝없이 숨겨 보내거나, 불가능한 격파 조건 때문에 리셋을 반복하게 만들지 않습니다. 적의 압도적인 전력과 후퇴 필요성을 전투 중 관찰할 수 있도록 설계하고, 퇴로를 확보할 행동 기회를 보장합니다. 적 증원은 출현 위치를 예고하고 아군 점유 칸에 즉시 생성하지 않습니다.

원작의 주요 결과는 유지하되 구출한 민간인, 확보한 물자, 보호한 후퇴로는 결과 화면과 후속 대사에 남깁니다. 원작에서 생존 여부가 정해진 인물을 선택 목표로 살릴 수 있다고 암시하지 않습니다. 구조 실패를 기록하는 범위와 인물은 시나리오별로 정합니다.

로시나 학선인이 필수 탈출 전에 쓰러지면 해당 전투의 실제 실패로 처리합니다. 반면 탈출 목표를 달성하면 캠페인은 진행됩니다. 주요 목표 전환에서 재도전 지점을 두고, 전환·구출·보상 상태가 저장 후 중복 실행되지 않도록 합니다.

## C++ 구조와 저장

| 영역 | 역할 |
|---|---|
| 기존 `native/engine/` | 렌더링·입력·한국어 글꼴·음향·햅틱을 재사용합니다. 전투나 원작 인물을 알지 않습니다. |
| 현재 `native/app/srpg/BattleModel.*` | 격자·인물·턴·행동·기력·승패 상태를 소유하고 명령을 검증합니다. Android·GLES 의존성을 두지 않습니다. |
| 예정 `Pathfinding.*`, `CombatRules.*` | 비용 기반 경로와 피해·반격·방어를 계산합니다. 예측과 실제 판정은 같은 규칙을 사용합니다. |
| 예정 `BattleAI.*` | 플레이어와 같은 명령 검증을 거쳐 적의 이동·대상을 선택합니다. |
| 현재 `BattleScene.*` | 지도·범위·정보·명령 확인·연출·터치 상태를 담당합니다. |
| 예정 `Scenario.*`, `Campaign.*` | 맵 정의·대화·목표 전환·시대·관계·수련·장 진행을 관리합니다. |

전투 명령은 원자적으로 적용하고 결과 이벤트를 반환합니다. 화면은 이 이벤트를 연출하며, 피해와 목표 판정이 프레임 시간에 좌우되지 않게 합니다. 경로 탐색은 선택·상태 변경 시 수행하고 매 프레임 반복하지 않습니다. 인물·기술·지형·시나리오 수치는 모델과 분리한 데이터로 정의합니다.

현재 수련장은 세로 화면과 안전 영역에 맞춰 표시합니다. 다인 전투로 확장할 때 가로 화면·카메라·지도 좌표 변환과 터치 영역을 검토합니다.

현재 저장은 `wuten-v1.txt`에 인물 위치·체력·기·턴·배움·수련 입장 상태·승패를 기록합니다. 임시 이동과 선택 상태는 저장하지 않습니다. 잘못된 데이터는 거부하고 임시 파일 교체로 저장합니다. 캠페인 확장 시 진영·행동 완료·목표 단계·일회성 이벤트·장 진행과 전투 완료 ID를 추가해 보상 중복을 막고 마지막 확정 상태를 복원합니다.

## 검증과 완료 기준

첫 장은 다섯 맵의 진입·대화·전투·결과·저장·재도전·장 완료까지 이어져야 합니다. 피해 예측 일치, 장애물·점유를 반영한 이동, 중복 행동 방지, 반격 연쇄 방지, 적법한 AI, 목표 전환과 보상 중복 방지를 테스트합니다. 수치 밸런스는 각 맵의 승리 가능한 행동 기록과 함께 확인합니다.

재미 검증에서는 플레이어가 다음 적 턴의 위험을 설명할 수 있는지, 서로 다른 행동 순서가 결과를 바꾸는지, 공격 외 행동이 실제로 유효한지 확인합니다. 전투를 실행할 수 있다는 사실만으로 재미가 검증됐다고 기록하지 않습니다.

새 진입점을 연결할 때 CMake·Android 진입점·화면 방향·한국어 글리프·SDD·검증 문서를 함께 갱신합니다. 세 수련전의 수치·완주 가능성·입력·저장은 검증 기록에 정리했습니다. 전체 캠페인과 사용자 재미, 장시간 실기기 성능은 아직 검증하지 않았습니다.
