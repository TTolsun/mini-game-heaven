# 0.6.0 — 도장 그래픽 시제품

- C++ 엔진을 유지하고 1280×720 가로 렌더 타깃, 안전 영역과 여백 입력 처리를 추가했습니다.
- 큰 인물 초상화, 48px 타일, 48×64 모듈형 유닛 8벌·네 방향·여섯 동작을 적용했습니다.
- 도장·숲·길·강을 한 테마로 구성하고 타격→밀림→추격을 순서대로 표시합니다. 실제 BFS 경로를 따라 걷습니다.
- 공격·발차기·기탄·빔·충돌·회복·기 축적 효과와 연출 절제 설정을 추가했습니다.
- WUTEN 2 저장과 전투 수치를 유지합니다. 그래픽 제작 규격·프롬프트·원본 기록을 문서화했습니다.

ARM64·x86_64 Debug/Release 빌드와 lint, 두 기기의 모델·표현·Scene 테스트가 통과했습니다. JVM 테스트는 NO-SOURCE입니다. API 36 에뮬레이터에서 대화·도장·발경/추격·기공파와 저장 결과를 확인했습니다. Galaxy S25+ / Android 16에 기존 설치를 유지한 서명 업데이트와 패키지 버전 확인을 마쳤으며, 보안 잠금 때문에 새 화면의 직접 검증은 대기 중입니다.

한 개의 그래픽 테마를 다섯 전투에 재사용합니다. 주변 강·숲·다리는 장식입니다. AI 초상화의 실제 원본은 셀당 418px입니다. 지도별 독립 아트, 영웅 전용 세부 포즈, 지형 파괴와 전체 성장기 캠페인은 후속 범위입니다. 공개 릴리스나 태그는 만들지 않습니다. 상세 근거는 docs/validation.md와 docs/art/style-guide.md를 참조합니다.
