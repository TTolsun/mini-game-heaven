# 0.5.0 — 도장과 동료의 다섯 전투

스토리 → 도장 정비 → 출전 준비 → 진영 턴 전투 → 전리품·성장·관계의 루프를 연결했습니다. 로시·학선인·창작 동료 란란, 적 네 유형, 다섯 맵과 열 기술을 포함합니다. 위치 조정·넉백·동료 추격·기 활용을 전투의 중심으로 삼습니다.

도장은 수련·연구·장비·동료·휴식을 제공하고, 출전에서는 인원과 시작 칸을 정합니다. 관찰과 실전 사용으로 얻은 기술 조건은 도장에서 연구합니다. 승리 보상은 맵마다 한 번이며 패배는 출전 체크포인트로 재도전하거나 정비할 수 있습니다. 새 저장 파일은 wuten-v2.txt이며 이전 수련장 파일을 덮어쓰지 않습니다.

ARM64·x86_64 Debug/Release 빌드·lint, Galaxy S25+ Android 16 및 에뮬레이터의 모델·Scene 검사가 통과했습니다. 자동 정책으로 다섯 맵을 완주했고 열 기술·예측·추격·충돌·저장·보상 중복을 확인했습니다. 실제 에뮬레이터 UI에서 발경 피해 18·추격 1의 예측과 실행을 대조했습니다. 실기기에 기존 앱을 삭제하지 않고 업데이트했으며 화면과 짧은 프레임 표본을 확인했습니다.

추격 없이도 쉬운 경로가 남아 있어 연계를 유도하는 맵 배치의 플레이테스트가 필요합니다. 임시 아트·짧은 대화·파티 공통 관계를 사용하며 전체 성장기, 절벽·지형 파괴·상점은 후속 범위입니다. 상세 근거는 [검증 기록](../validation.md)과 [설계](../srpg-design.md)에 있습니다. 공개 릴리스나 태그는 생성하지 않습니다.
