# 마물 정원 0.2.1

몬스터 6종을 비인간형 셀 채색 일러스트로 교체했습니다. 지도·도감·합성·결과 화면에서 같은 이미지 시트를 사용합니다. 몬스터 이름, 능력치, 합성 규칙과 저장 형식은 유지합니다. SDD 시작 페이지의 제목 아래에는 물방울 슬라임을 표시하며 문서 생성·검사 과정에서 동일하게 삽입합니다.

## 빌드 및 지원 범위

- 패키지: `com.ttolsun.minigameheaven`, versionName `0.2.1`, versionCode `3`.
- Android 9(API 28) 이상, ARM64 및 x86_64를 빌드합니다.
- 새 정식 RSA 4096 서명키로 서명하며 Release의 debuggable 플래그는 꺼져 있습니다.
- 인증서 SHA-256: `71525024098706c7deebc1d315a29403b395ff313304a0b1073eb22e68eabfb3`.

## 실제 검증

- 2026-09-19: Debug·Release 빌드와 lint를 통과했습니다. JVM 단위 테스트 대상은 없습니다(NO-SOURCE).
- 네이티브 모델·Scene 회귀 검증: 합성 3종, 저장·손상 파일, 10일 캠페인, 합성 확인 후 연속 입력과 BACK 처리를 통과했습니다(x86_64 에뮬레이터).
- SM-S936N, Android 16: 기존 개발용 앱의 데이터와 APK를 백업하고 새 서명으로 교체했습니다. 복원 직후 `castle-v1.txt`를 바이트 단위로 대조했습니다. 최종 Release 설치 후 기존 2일 차 진행 상태와 새 몬스터 그림을 확인했습니다.
- SDD 제목 아래에 대표 캐릭터 한 마리가 표시되는 것을 브라우저에서 확인했습니다. 이미지 데이터를 HTML에 포함하므로 이미지 파일을 따로 배포할 필요가 없습니다.

## 알려진 한계

네이버 참고 글의 본문은 접근 제한으로 확인하지 못했으며, 해당 글을 기준으로 한 게임 규칙 재설계는 이번 버전에 포함되지 않았습니다. 여러 기기의 장시간 성능·배터리·오디오 경로 변경은 검증하지 않았습니다. 최초 서명 전환 때에는 기존 개발용 앱과 서명이 달라 데이터 백업·복원 절차가 필요하며, 이후 업데이트에는 동일한 릴리스 키를 유지해야 합니다.
