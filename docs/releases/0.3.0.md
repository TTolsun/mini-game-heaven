# 마물 정원 0.3.0

성을 꾸민 동선에 따라 용사가 침공합니다. 성 꾸미기 → 통로 편집에서 이웃 방과 통로를 열거나 닫고 왕좌를 옮길 수 있습니다. 금빛으로 표시한 최단 경로가 실제 이동·교전 경로이며, 왕좌까지 길이 끊기면 방어를 시작할 수 없습니다. 열린 방과 맞닿은 칸을 골라 확장할 수 있습니다.

## 빌드 및 지원 범위

- 패키지: `com.ttolsun.minigameheaven`, versionName `0.3.0`, versionCode `4`.
- Android 9(API 28) 이상, ARM64 및 x86_64를 지원합니다.
- 0.2.1과 동일한 정식 키로 서명하여 앱 삭제 없이 업데이트합니다.
- 인증서 SHA-256: `71525024098706c7deebc1d315a29403b395ff313304a0b1073eb22e68eabfb3`.
- 필수 CI를 통과한 main 커밋에서 로컬 서명·검증한 APK를 배포합니다. 서명키와 비밀번호는 GitHub로 전송하지 않습니다.
- 기존 저장 데이터를 유지하며 CASTLE 1을 통로·왕좌를 포함한 CASTLE 2로 이전합니다. 새 저장 파일을 이전 버전에서 읽는 역호환은 지원하지 않습니다.

## 검증

기능 구현 PR #15에서 ARM64/x86_64 Debug·Release 빌드, lint, 정책 검사와 SDD 검사를 통과했습니다. API 36 에뮬레이터에서 경로 변경에 따른 전투 결과, 단절된 경로 차단, 저장 이전·손상 그래프 거부, 연속 입력·BACK 처리, 10일 캠페인을 검증했습니다. 1080×2400 및 720×1280 화면에서 편집과 용사 이동을 확인했습니다. 0.3.0의 Debug·Release 빌드와 lint도 통과했으며 JVM 단위 테스트는 NO-SOURCE입니다. 정식 인증서와 패키지·버전·debuggable 비활성 상태를 배포 도구로 검증했습니다.

2026-09-19 SM-S936N(Android 16)에서 0.2.1을 삭제하지 않고 0.3.0으로 업데이트했습니다. 설치 전후 4일 차·금화 165·마력 104·마물 5마리의 종/레벨/배치·도감 2종이 유지되는 것을 화면에서 확인했습니다. 최초 설치 시각도 유지됐습니다. 저장 파일의 바이트 단위 대조는 수행하지 않았습니다.

## 알려진 한계

탐험·모집 확장·진화·성 등급과 몬스터의 자유 이동은 후속 구현입니다. 긴 경로의 전략적 우위와 빠른 패배 반복 보상은 추가 밸런스 검토가 필요합니다. 여러 실기기에서의 장시간 성능·배터리 검증은 아직 수행하지 않았습니다.
