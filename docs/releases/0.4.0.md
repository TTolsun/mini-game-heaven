# 0.4.0 — 무술 SRPG 수련장 (개발 버전)

C++ 핵심 엔진을 유지하며 전투 중 간파·모방·체득을 검증하는 세 수련전으로 개편했습니다. 로시는 다른 행동으로 기술의 단서를 얻고, 미완성 모방을 실전에서 성공시켜 자기 기술로 만듭니다. 기 축적의 노출 위험, 방향 예고, 밀쳐내기와 벽 충돌을 포함합니다.

이전 게임의 전용 소스·테스트·자산·문서와 도구를 제거했습니다. 프로젝트·라이브러리·namespace·테마를 무천으로 변경하고 기존 설치 업데이트를 위한 applicationId는 유지했습니다. 전투 저장은 wuten-v1.txt에 별도로 기록합니다.

ARM64·x86_64 Debug/Release 빌드와 lint, x86_64 API 36 에뮬레이터와 Galaxy S25+ (Android 16)의 모델·Scene 테스트가 통과했습니다. 실제 터치로 배움에서 첫 수련 승리까지, 세 화면 크기와 저장 복원을 확인했습니다. 실기기는 기존 0.3.0에서 삭제 없이 업데이트했고 다음 수련으로 기술이 계승되는 것을 확인했습니다. 상세 내용은 [검증 기록](../validation.md)을 참조합니다.

현재 세 수련전은 재미 검증용이며 전체 1장이나 캠페인이 아닙니다. 임시 도형 캐릭터와 단순 적 AI를 사용하며 체득 이후 난도가 낮습니다. 이번 작업은 PR 병합 대상이며 공개 릴리스나 버전 태그를 생성하지 않습니다.
